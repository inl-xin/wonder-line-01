Entry for the make.fun bounty `u-pangg7-one-line-of-wonder-ee10fcd8`
("One Line of Wonder"), by @inl-xin.

One line: the snowflake you caught on your tongue when you were
seven has been drunk twice since, and is rain again this minute.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
